# Students Supporter (Plan-It) 🚀
> An Interactive Web App built by a Class 10 Student to tackle Student Stress, Burnout, and Career Confusion.

## 🔗 Live Project URL
👉 https://softr.app

## 🌟 The Problem
As a school student, I realized that we spend 80% of our time searching for strategies, plans, and books, and only 20% actually studying. This creates "Analysis Paralysis" and immense exam stress.

## 🛠️ The Framework & Solution
I designed a 3-tab framework to give students direct, actionable support without overwhelming them:
1. **Survival Guide (Class 8, 9, 10):** Actionable, no-nonsense academic hacks (Active recall, 1-page notes, sample paper strategy).
2. **Mind Spa:** A safe mental health zone dealing with distractions, family pressure, confidence, and emotional release.
3. **Future Finder:** A step-by-step career path analyzer covering subject analysis, core interests, and alternative 'Plan B' routes.

## 💻 Tech Stack Used
- **Frontend / UI:** Softr.io (No-Code App Architecture)
- **Database / Backend:** Google Sheets
